# SkillSprint Demo Script (4–5 minutes)

1. **Introduction:** SkillSprint is an AI-powered interview preparation assistant that combines role-specific practice, answer feedback and progress tracking.
2. **Problem:** Candidates often practise generic questions without consistent evaluation or a clear way to identify weaknesses.
3. **Setup:** Select a target role, experience level, category and optionally paste a job description.
4. **Question generation:** Generate questions using the configured LLM. Explain that role/context are sent to the model and structured questions are returned.
5. **Evaluation:** Submit an answer. Explain the four criteria: technical accuracy, relevance, completeness and clarity. Show strengths, missing points and an improved answer.
6. **Progress:** Complete the session and show recommendations, performance chart and saved history.
7. **Technology:** Python, Streamlit, Gemini/Claude API, SQLite and Plotly. Explain that an existing LLM is integrated, not trained.

Record the actual working app. Show a real API-backed session, hide API keys, speak in your own words and be prepared to explain each feature.
